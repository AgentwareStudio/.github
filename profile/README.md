**Agentware is a class of software designed for the agentic era.**
You entrust it with a goal; within authorized bounds it organizes actions, executes tasks, and delivers verifiable outcomes.

Agentware Studio is an independent research and creation lab built around this paradigm. We study how software shifts from operating interfaces to delegating intent, teach what we learn, and test the ideas in real products.

### What we work on

- **[Open Curriculum](https://agentware.studio/learn/)**: a structured AI course in three seasons, Fundamentals, AI Coding, and Building AI Systems.
- **[Research & Essays](https://agentware.studio/blog/)**: essays and field notes on agentic software design, memory systems, and human–agent collaboration.
- **[User Tools](https://aikit.pro)**: AI tools at aikit.pro, where intent-driven software meets everyday work.

### The Agentware Manifesto

```text
I.    Software should understand intent, not just input
II.   Software should execute goals, not just expose functions
III.  Paths may adapt; outcomes must remain verifiable
IV.   Autonomy requires governance
V.    Memory turns software from a tool into an evolving system
VI.   The future unit of software is not the feature; it is the delegation
```
